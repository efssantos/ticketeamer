# Changelog

## 1.0.0 - 2026-08-21

- Initial release.
- GLPI 11.0.x compatibility target.
- Ticket `item_add` hook.
- Category → technical group → active group users routing.
- Queue-based asynchronous delivery.
- Microsoft Entra OAuth 2.0 authorization-code flow with refresh token.
- Microsoft Graph private one-to-one Teams chat delivery.
- Retry and failure handling.
- GLPI configuration page using a GLPI 11 controller and Twig.
