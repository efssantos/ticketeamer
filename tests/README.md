# Testes

Os testes automatizados de integração com Microsoft Graph não são executados por padrão porque exigiriam credenciais reais e um tenant Microsoft.

Para testes de produção controlados:

1. Use um tenant de homologação.
2. Crie uma conta técnica exclusiva.
3. Configure apenas um grupo técnico de teste.
4. Crie uma categoria ITIL de teste.
5. Abra um chamado de teste.
6. Confirme a fila.
7. Execute o cron manualmente.
8. Confirme a conversa privada no Teams.
